================================================================================
                        QUALITY GATES DETAILS
================================================================================

    qa_tests
    ├─ Input: Test execution results from CI
    ├─ Criteria: ALL tests pass
    ├─ DEV: Unit + integration tests 100%
    ├─ HML: Coverage >80%, all tests pass
    ├─ PROD: Coverage >85%, all tests pass
    └─ Evaluator: QA-MCP / TestRunner

    pr_approved
    ├─ Input: GitHub PR reviews
    ├─ Criteria: At least 1 approval, no changes requested
    ├─ DEV: 1 approval minimum
    ├─ HML: 1 approval minimum
    ├─ PROD: 1 approval minimum
    └─ Evaluator: Human (via GitHub UI)

    security_scan
    ├─ Input: SAST + SCA + secrets + license scan results
    ├─ Criteria: No critical/high findings
    ├─ DEV: Not required
    ├─ HML: Not required
    ├─ PROD: REQUIRED - all checks must pass
    └─ Evaluator: Security / Security Scanner

    health_check
    ├─ Input: Service health endpoint response
    ├─ Criteria: HTTP 200 within 2 seconds
    ├─ DEV: Not evaluated (local)
    ├─ HML: Optional (post-deployment)
    ├─ PROD: REQUIRED - validates deployment success
    └─ Evaluator: Pipeline Health Monitor

                          SUMMARY METRICS
================================================================================

    Timeline per Release:
    ├─ DEV (automatic)         : ~5 min   (GitHub CI)
    ├─ HML (manual approval)   : ~15 min  (human + deploy)
    ├─ PROD (manual approval)  : ~20 min  (human + canary + rollout)
    └─ TOTAL (end-to-end)      : ~40 min  + human review time

    Quality Gates (8 Services × 3 Environments):
    ├─ DEV: 2 gates × 8 = 16 gates evaluated automatically
    ├─ HML: 2 gates × 8 = 16 gates evaluated automatically
    └─ PROD: 4 gates × 8 = 32 gates (human + automatic)

    Observable Metrics:
    ├─ Gate Pass Rate: Target >95%
    ├─ Promotion Success: Target 100%
    ├─ Mean Cycle Time: Target <1 hour per environment
    ├─ Mean Time to PROD: Target <2 hours total
    └─ Rollback Success: Target 100%
